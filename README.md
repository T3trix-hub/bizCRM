# BizCRM — CRM для малого бизнеса

Современная CRM-система для управления клиентами, сделками и задачами. Чистый JavaScript, без фреймворков и зависимостей. Все данные хранятся в LocalStorage — никакого бэкенда.

## Функционал

### Дашборд
- Виджеты со статистикой: клиенты, активные сделки, выручка за месяц, задачи на сегодня
- График доходов по месяцам (чистый Canvas, без библиотек)
- Воронка продаж с визуализацией конверсии
- Лента последних активностей

### Клиенты
- Таблица с поиском, фильтрацией по статусу и сортировкой по любому полю
- Карточка клиента: контакты, компания, город, статус, заметки
- История взаимодействий: звонки, встречи, письма с датами
- Экспорт и импорт базы клиентов в CSV

### Сделки (Kanban)
- Доска с колонками: Новая → В работе → На проверке → Закрыта (выиграна/проиграна)
- Drag-and-drop перемещение карточек между колонками
- У каждой сделки: сумма, клиент, дедлайн, приоритет, теги, заметки

### Задачи
- Список с чекбоксами и фильтрами по приоритету и статусу
- Привязка задачи к клиенту или сделке
- Просроченные задачи подсвечиваются красным, срочные — жёлтым

### Календарь
- Месячный и недельный вид
- Задачи и дедлайны сделок отображаются на датах
- Клик по дню открывает форму создания задачи

### Аналитика
- Графики: выручка по месяцам, конверсия воронки, активность по дням
- Топ-5 клиентов по сумме сделок
- Экспорт всей базы в JSON и импорт обратно

## UI/UX
- Тёмная и светлая тема (переключатель, сохраняется)
- Мультиязычность: русский / английский
- Адаптивный дизайн — sidebar сворачивается в бургер на мобильных
- Плавные анимации переходов между страницами
- Дизайн в стиле Linear / Notion

## Демо-данные
При первом запуске автоматически загружаются:
- 15 клиентов с реалистичными русскими именами, городами РФ/СНГ, телефонами +7
- 12 сделок с реальными названиями и суммами от 50 000 до 500 000 ₽
- 18 задач с разными приоритетами и дедлайнами
- История взаимодействий у каждого клиента

## Технологии
- **HTML5 / CSS3 / Vanilla JavaScript** — без фреймворков
- **LocalStorage** — хранение всех данных на стороне клиента
- **Canvas API** — графики без Chart.js и других библиотек
- **CSS Custom Properties** — тёмная/светлая тема через переменные

## Структура файлов
```
index.html   — разметка всего приложения
style.css    — стили (CSS Variables, адаптив)
app.js       — вся логика: навигация, рендер, события
db.js        — слой данных: CRUD, демо-данные, экспорт
favicon.ico  — иконка для вкладки браузера
```

## Запуск локально

**Python:**
```bash
python3 -m http.server 3000
# открыть http://localhost:3000
```

**Node.js:**
```bash
npx serve .
```

**VS Code:** расширение Live Server → правой кнопкой на index.html → Open with Live Server
